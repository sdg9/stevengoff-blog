The **stef-clock** repository starts with a Fitbit watchface in January 2019. Within a short run of commits, the work moves through weather, steps, time formatting, multiple screens, and smart-home integration.

A watch is a useful constraint. There isn't much room to explain a feature, and the person looking at it probably isn't settling in for a long session.

## A glance is a different interaction

The commit history includes details such as hiding the weather when it hasn't populated and adjusting the way time and step counts appear. Those are small changes, but they fit the device: incomplete information shouldn't look like a trustworthy reading, and familiar information should be easy to recognize.

On January 28, the messages move from multiple screens and integration work to “Smart home working.” That is a recorded development milestone, not a promise about every device or later firmware version.

What I like about this project is how it connected interests that were already present. The house had become programmable. Mobile interfaces were familiar territory. A watch offered a new place to bring those pieces together.

It also changes the question slightly. Instead of asking what else I can put on a screen, the watch asks what is worth seeing in a brief glance. That is a useful design question even when the next project has a much larger display.
