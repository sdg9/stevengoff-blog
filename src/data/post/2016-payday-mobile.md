I've already written the bigger [Payday calculator story](/01-spark-era-payday2-millions): the audience, the mobile apps, and the pizza purchase that made it feel real. The July 2016 repository offers a smaller view of that same period.

The commits move from initial setup on July 10 to skill images, image-loading work, package changes, and builds on July 11. Those aren't dramatic milestones by themselves. Together, they show the ordinary work between having useful information on a website and making it usable inside an app.

## The skill tree was only part of the job

A companion app needs the game information, but it also needs assets to arrive, dependencies to cooperate, and a build that can actually run on a phone. That is the part of mobile development a screenshot tends to hide.

This archive entry belongs to that transition. The repository is evidence of the React Native implementation effort, not a timestamp for every sale or audience milestone in the larger story. Those memories cover a broader period.

The project also makes a useful connection to the tools I would build later. A game supplied a reason to learn a mobile framework. Getting the app working supplied a reason to learn the surrounding build and delivery process.

That is still a good description of how I pick up technology: start with something I want to use, then follow the problems it creates.
