**RewardsPoints** had a very small premise: help me remember which payment card was useful in a particular situation.

The repository description calls it a React Native reminder app. Its January 2018 history is mostly about updated reward data and delivery plumbing, including App Center and CodePush configuration.

That combination is more revealing than a long feature list would be. The interface could stay fairly simple, but the information behind it changed with time.

## A reminder needs current information

For this kind of app, the difficult part isn't necessarily drawing another screen. It is making sure the answer still means something when the categories change.

The January 14 commits capture both sides: update the rewards, then work on the path for getting updates into the app. Later history returns to the same theme with another quarter's reward information.

I like the modest scope here. This wasn't a financial-planning platform. The documented purpose was to reduce a small recurring memory task.

Looking back, it belongs with the timers, sticker boards, and other personal utilities I kept building. A useful project doesn't always need to introduce a new capability. Sometimes it just puts an answer where I can find it at the moment I need it.
